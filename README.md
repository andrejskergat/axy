# Socialfin — Ad Creatives Dashboard

A password-protected gallery for sharing ad creatives with clients, built with Next.js 14 (App Router), Tailwind CSS, and TypeScript.

---

## 1. Install and run locally

```bash
npm install
npm run dev
```

The app runs at [http://localhost:3000](http://localhost:3000).

---

## 2. Generate a password

Use the included script to set a password that expires in 72 hours:

```bash
node scripts/generate-password.js mypassword123
```

This writes `data/auth.json` (gitignored) with the password and expiry timestamp. Share the password with your client — after 72 hours it stops working automatically.

---

## 3. Add media files

1. Copy image or video files into `public/media/`.
2. Add corresponding entries to `data/media.json`:

```json
[
  {
    "id": "unique-id-1",
    "title": "Summer Campaign Hero",
    "client": "Acme Corp",
    "type": "image",
    "filename": "summer-hero.jpg",
    "tags": ["social", "instagram", "summer"]
  },
  {
    "id": "unique-id-2",
    "title": "Brand Video 30s",
    "client": "Acme Corp",
    "type": "video",
    "filename": "brand-video-30s.mp4",
    "tags": ["video", "brand", "30s"]
  }
]
```

Supported image formats: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`  
Supported video formats: `.mp4`, `.webm`, `.mov`

## Project structure

```
data/
  auth.json          # gitignored — generated by generate-password script
  auth.example.json  # example format for auth.json
  media.json         # media metadata array
public/
  media/             # gitignored media files go here
scripts/
  generate-password.js
src/
  app/               # Next.js App Router pages & API routes
  components/        # React components
  lib/auth.ts        # Auth + media helpers
```

---

## Security notes

- `data/auth.json` is gitignored and never committed.
- The session cookie (`sb_session`) is `httpOnly` and `sameSite: lax`.
- Every protected page and API route re-validates the session password against `auth.json` on each request.
- After the password expires, all sessions are invalidated immediately.
